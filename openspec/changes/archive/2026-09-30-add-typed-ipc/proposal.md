## Why

Tauri v2 does no type checking across IPC. A renamed command, argument key or field only fails at runtime, in the webview. G-005 asks to prove the frontend-to-Rust channel with a typed command before Phase 1 and Phase 2 add real ones: opening, saving and settings.

The approach was decided in [How do Rust and TypeScript share IPC command types?](https://github.com/Acero-AD/quiro/issues/12). How the bindings get written under the harness was decided in [How does a worker regenerate the IPC bindings when the guard blocks cargo test?](https://github.com/Acero-AD/quiro/issues/21).

## What Changes

- The operator adds tauri-specta and specta, pinned exactly, before the run.
- A typed `ping` command replaces the starter `greet`:
  - it takes a request struct and returns a reply struct, or a typed error;
  - its error is a data-carrying enum with adjacent tagging.
- The TypeScript bindings are generated by tauri-specta into `src/bindings.ts` and checked in. The frontend calls Rust only through them.
- A Rust drift test fails `cargo test` when `src/bindings.ts` is stale. Its failure message contains the full expected file, so a harness worker can copy it.
- `cd src-tauri && UPDATE_BINDINGS=1 cargo test` regenerates the file locally.
- `tsc` in `npm run build` type-checks the frontend against the bindings.
- The starter page (greet form, logos and links) is replaced by a minimal page that shows Rust's reply to `ping`. That page is temporary: G-101 replaces it with the editor. `ping`, its client module and their tests stay as the reference example of the IPC pattern.

## Capabilities

### New Capabilities

- `ipc-bindings`: how frontend code calls Rust (generated, checked-in, drift-checked bindings), the `ping` reference command, and the page that shows its reply.

### Modified Capabilities

None.

## Impact

- **Operator prerequisites, before the run:**
  - edit `src-tauri/Cargo.toml` to add the `tauri` feature `specta` and the crates `specta`, `specta-typescript` and `tauri-specta`, pinned with `=`;
  - update `src-tauri/Cargo.lock` and fetch the crates into `~/.cargo/registry`;
  - take a new harness baseline.
- **Rust code:** a new `src-tauri/src/ipc.rs`, and `src-tauri/src/lib.rs` switches to the tauri-specta builder. `greet` is removed.
- **Frontend code:**
  - new files: `src/bindings.ts` (generated) and `src/ping.ts`;
  - rewritten: `index.html`, `src/main.ts` and `src/styles.css`;
  - `src/assets/` (the starter logos) is removed.
- **Run order:** second, after `add-window-basics` and before `add-frontend-tooling`. The frontend tooling change writes its first Vitest test against `src/ping.ts`.
