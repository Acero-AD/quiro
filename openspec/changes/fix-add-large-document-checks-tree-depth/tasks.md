## 1. Gate tests for shallow chunk reuse

- [ ] 1.1 `src/editor/chunk-reuse.test.ts` is rewritten as `design.md` describes. Through `newState(generateLargeDocument(DEFAULT_LARGE_DOCUMENT_SEED))` and `ensureSyntaxTree(state, state.doc.length, 1e9)`, it collects the balanced (anonymous) chunks of the old tree and of the tree after inserting `"x"` at the end. It walks each tree with a cursor in `IterMode.IncludeAnonymous` that enters only anonymous nodes. It expects at least 100 chunks in the old tree, and at least 90% of them in the new tree as the same objects. It no longer requires the old tree's first chunk to be reused.
- [ ] 1.2 A new jsdom test file in `src/editor/` writes 300 paragraphs, each ``Paragraph ${i} with *some* text.\n\n``, one at a time into a `newState("")` state through `state.update`. It does this three times: at the start, in the middle (just after the last `"\n\n"` before the document's midpoint, or at 0 if there's none), and at the end. It completes the parse with `ensureSyntaxTree` after each insertion. In each case, it expects the depth of the final tree to be at most 5 more than the depth of `markdownMode().language.parser.parse` of the same text, counting levels of `Tree` children only.
- [ ] 1.3 No file under `src/` other than these two test files is added or changed. `src/editor/incremental-parse.test.ts`, `src/editor/fixtures/dialect.tree.txt`, `package.json`, `package-lock.json` and `scripts/patch-lezer-markdown.mjs` are unchanged by this section.
- [ ] 1.4 `npm run lint`, `npm test` and `npm run build` pass in the gate.
